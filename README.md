# 숲속친구들 키우기 (사자대장의 학습 앱)

퀴즈를 풀어 먹이를 얻고, 사자·토끼·여우 친구를 6단계로 진화시키며 숲을 꾸미는 학습 웹앱입니다.

## 구성

빌드 과정이 없는 정적 사이트이며, 저장소 루트가 그대로 배포 루트입니다.

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 화면 뼈대와 스타일 |
| `app.js` | 화면 전환, 육성·진화·장식 상점, 저장 로직 |
| `content.js` | 캐릭터 정보와 문제 데이터 (통합과학·통합사회·한국사, 60단원 / 180문제) |
| `additional-questions.js`, `challenge-questions.js` | 추가·도전 문제 |
| `play-motion.js`, `quiz-sounds.js`, `forest-music.js` | 놀이 동작, 효과음, 배경 음악 |
| `pet-*-stage-*.webp`, `motion/`, `ornaments/`, `props/` | 캐릭터·장식·소품 이미지 |
| `forest-opening.mp4`, `forest-opening.m4a`, `run-*.png` | 오프닝 영상·소리와 대체 애니메이션 |

## 배포

Vercel 프로젝트의 배포 루트를 이 저장소 루트로 설정합니다. 업데이트는 파일을 수정한 뒤 같은 정식 주소로 다시 배포합니다.

## 학습 기록

진행 상황은 현재 기기·브라우저의 `localStorage`(`lion-grow-v2`)에만 저장됩니다. 브라우저 데이터를 지우면 기록도 사라지며, Supabase 연결은 아직 적용하지 않았습니다.

## 문제 추가할 때 주의

저장된 진행 기록은 단원·문제 번호로 연결됩니다. 새 단원은 항상 기존 단원 **뒤에** 추가하고, 기존 단원의 순서나 문제 순서는 바꾸지 마세요.
